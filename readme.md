
# 🚀 CryptoM5 - Cryptocurrency Landing Page

## 📌 Project Overview

CryptoM5 is a simple cryptocurrency landing page created using pure HTML. The project is designed to showcase a crypto trading platform with multiple sections such as Features, About, Traders, Skills, Clients, Contact Form, and Google Maps integration.

This project is suitable for beginners who are learning HTML page structure and webpage layout without using CSS frameworks or JavaScript.

---

## ✨ Features

- Responsive-style page layout using HTML tables
- Navigation Bar
- Hero Banner Section
- Features Section
- About Us Section
- Traders/Team Section
- Skills Section
- Client Logos Section
- Google Maps Integration
- Contact Form
- Footer with Social Media Links

---

## 🛠 Technologies Used

- HTML5
- Basic HTML Elements
- Tables for Layout
- Forms
- Images
- Google Maps Embed
- Hyperlinks

## ▶️ How to Run

1. Download or clone the repository.
2. Make sure all images are placed inside the **img** folder.
3. Open **index.html** in any modern web browser.

- HTML document structure
- Creating navigation menus

- Adding images and hyperlinks
- Creating forms
- Embedding Google Maps
